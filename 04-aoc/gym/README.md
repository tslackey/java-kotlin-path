# AoC gym (original problems)

AoC-shaped: multiline input, `part1`, `part2`. Stories and samples here are ours so we can ship tests without copying Advent of Code.

```bash
./gradlew :aoc-gym:test
```

| Exercise | Skills | After |
| --- | --- | --- |
| `AltitudeLog` | scan a string, first index | Junior fundamentals |
| `ReceiptBatches` | blank-line groups, sort | Junior collections |
| `ReachableCells` | grid BFS | Mid |
| `MergeWindows` | interval merge | Mid |
| `CheapestClimb` | Dijkstra / 0-1 costs | Senior performance |

Implement Java (`path.aoc.gym.j`) **and** Kotlin (`path.aoc.gym.k`).
